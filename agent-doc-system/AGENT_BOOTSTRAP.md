# Agent Bootstrap

Read `AGENTS.md` first, then consult `docs/README.md` and the documents relevant to the task.

## Operating Loop
UNDERSTAND → PLAN → DESIGN → IMPLEMENT → TEST → REVIEW → DOCUMENT → VERIFY

## Core Rules
- Do not invent project facts; mark unknowns.
- Inspect existing code before changing it.
- Keep changes bounded and reversible.
- Verify claims with tests or observable evidence.
- Protect secrets and sensitive data.
- Update canonical docs when durable decisions change.
