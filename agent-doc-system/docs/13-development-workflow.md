# Development Workflow

Every meaningful change follows:

```text
UNDERSTAND → PLAN → DESIGN → IMPLEMENT → TEST → REVIEW → DOCUMENT → VERIFY
```

## Feature Workflow
1. Read applicable project documents.
2. Inspect the existing implementation.
3. Identify constraints and dependencies.
4. Create a bounded implementation plan.
5. Implement the smallest coherent change.
6. Run targeted tests first.
7. Run lint/type/static checks.
8. Review the diff for unrelated changes.
9. Update required documentation.
10. Verify acceptance criteria.
