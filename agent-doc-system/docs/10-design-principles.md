# Design Principles

## DO
- Reuse established components and patterns.
- Make hierarchy and primary actions obvious.
- Prefer accessible defaults.
- Keep interaction feedback immediate and clear.
- Design error and empty states intentionally.

## DON'T
- Add decorative complexity without purpose.
- Introduce inconsistent component variants.
- Hide essential status in color alone.
- Create one-off styles when a system pattern exists.
- Use animation that harms usability.
