# Feature Completion Checklist

- [ ] Requirement is clearly mapped to implementation.
- [ ] Acceptance criteria are met.
- [ ] Existing patterns were reused where appropriate.
- [ ] Relevant unit/integration/UI/E2E/AI tests exist.
- [ ] Static checks pass.
- [ ] Error and edge states are handled.
- [ ] Security implications reviewed.
- [ ] Accessibility reviewed where relevant.
- [ ] Performance implications reviewed where relevant.
- [ ] Documentation updated.
- [ ] Git diff contains no accidental changes.
- [ ] Verification evidence is available.
