# Quality Assurance

## Release Gate
- [ ] Requirements satisfied
- [ ] Acceptance criteria satisfied
- [ ] Tests pass
- [ ] Type/static checks pass
- [ ] Lint/format passes
- [ ] No obvious regressions
- [ ] Accessibility checked where applicable
- [ ] Security considered
- [ ] Error states handled
- [ ] Documentation updated
- [ ] Git diff reviewed

A feature is not complete merely because the implementation compiles.
